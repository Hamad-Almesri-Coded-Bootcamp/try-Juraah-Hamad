## COMPONENT NOTES
- **StatusPill** — four statuses, glyph + word (`copy.vocabulary.<status>` unless `label`), `.wsf-pill--<status>`; the word is always present so colour is never alone. Root carries `data-testid="status-pill"` (the runtime G1 proof reads it).
- **SectorChip** — `ink-muted` word in a `border` chip; never a semantic colour.
- **Card** — `as` defaults to `button` when `onClick` is set; a `button` Card has a full-width hit area and `.wsf-focus`; `href` renders `<a>`.
- **PrescriptionCard** — `PrescriptionSummary` from `index.d.ts`; `dose` omitted → no status row; `strengthUnit` default `' mg'` appended after `strengthMg` **as written — never converted**; `onOpen` makes the whole card one button with the mirroring chevron.
- **DetailRow** — `null`/`undefined`/`''` → the em dash in `ink-muted` and an assistive `copy.vocabulary.empty`; **never** "undefined", never a collapsed row.
- **DepletionMeter** — does no arithmetic: renders `remaining`/`total` and `daysRemaining`; `daysRemaining <= lowAtDays` → `.wsf-dep--low` with the low-supply word; `null` → no days line. `role="meter"`? No: `role="progressbar"` with `aria-valuenow/min/max` and a text alternative.
- **DoseRow** (new, prompt 1) — props: `dose: { status: DoseStatus; tracked?: boolean }`, `drug: { genericName; brandName?; strengthMg?; strengthUnit? }`, `amountLabel` (already formatted, e.g. "حبة واحدة · ٥٠٠ mg"), `timeLabel?`, `href?` or `onOpen?` (**the only interaction: one link/button opening the prescription; nothing else is interactive**), `lang?`, `className?`. **Renders `StatusPill` only when `dose.tracked !== false`** — decided by `tracked`, never by the status word; when `tracked === false` the row is a calm plan entry (drug body-strong, amount, time) with no placeholder, no grey pill, no gap where a pill would be. Root `data-testid="dose-row"`. Tests: `{tracked:false, status:'upcoming'}` → no pill, no `button`/`input`/`role=button` other than the optional open control; `{tracked:false, status:'missed'}` → **still no pill** (defensive; the data never has it); `{tracked:true, status:'missed'}` → pill "فائتة". README states the read-only rule and the `tracked` rule verbatim.
- **ScheduleGroup** (new) — clock-time header (`timeLabel` formatted by the caller) grouping `children` DoseRows; correct with one and with several; `<section aria-labelledby>`; the clock glyph never mirrors.
- **DoseTimeline** (new) — compact vertical list of `{ dateLabel, timeLabel, status, tracked }` items; pills only for `tracked !== false`; read-only; correct with no statuses at all (the untracked patient's history is a list of times).
- **AlertRow** (new) — `severity`, `drugs: string[]`, `reviewStatus`, `title?`, `metaLabel?` (patient/sector line for the reviewer queue, e.g. "حمد سالم المطيري · قطاع عام"), `href?`/`onOpen?`; severity word + glyph (`copy.vocabulary.severity*`), review-state sentence (`copy.vocabulary.<reviewStatus>`), tokens per the brand book's status table; `pending_medical_review` is `warning`, never success/danger alone.
- **ActivityRow** (new) — `title`, `timeLabel`, `description?`, `href?`; optional `actor?: { label: string; kind: 'patient'|'caregiver'|'reviewer'|'admin'|'agent'|'system' }` (the **label** is the human word from the vocabulary — the `kind` only picks a glyph/tone; the literal role string is rendered **only** when the consumer passes it as a second `code?: string` prop, which X1 alone does — CR-010) and `patientRef?: React.ReactNode` (a masked name from the formatter). `layout: 'list' | 'table'` — the table layout is a `<tr>` for the audit log at 1440 (`ActivityRow.Table` header component beside it, or a `role="row"` grid; document the choice). Read-only.
- **MenuRow** (new) — `label`, `value?` / `description?`, `icon?`, `href?` or `onClick?`, `chevron` mirrors; `tone?: 'default' | 'relationship'` where a relationship state ("awaiting acceptance", "declined", "expired", "revoked") renders the value in `ink-muted` with **no badge, dot or alert icon**; also a `trailing?: React.ReactNode` slot for a Toggle in settings lists. 44px minimum, full-width hit area.
