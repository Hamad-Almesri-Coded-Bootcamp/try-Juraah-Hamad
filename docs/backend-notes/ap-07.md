are unverified or missing from the brand map, so Travel Check cannot resolve them. AP-07 has no

## What changed

SFDA drugs list (`https://www.sfda.gov.sa/en/drugs-list`, no login) on 2026-09-24 and filtered it by
`Trade Name` for MAREVAN, BRUFEN, GLUCOPHAGE and LIPITOR, and by `Scientific Name` for WARFARIN and
ATORVASTATIN (to see what the register does carry, since neither trade name it was looking for came
back). Six screenshots are in `docs/backend-notes/ap-07/` (copied byte for byte from the read

claim), not a data-entry fix, and AP-07 does not make that decision.

  METFORMIN HYDROCHLORIDE, DDInter indexes Metformin).

  was last retrieved 2026-09-20 and does not describe these two rows). `retrievedBy` read "owner
  approval requested in PR" and now reads "approved by the owner (Mohammad) on 2026-09-25": the
  owner's sign-off this file asked for (see *Owner's approval*, below).

  these" — that tool is not in this repository) is corrected to name the real mechanism:
  `buildBrandIndex`'s `row.verified !== true` skip in `src/resolve.js`.

"unverified name" fixture; since BRUFEN now resolves, G2 is repointed at `Lipitor 20`, a name that
