# AP-06 · DDInter rebuild with the seed scope

Branch `polish/ap-06-ddinter-seed-scope`. Plan § 7.3 AP-06, finding 3. Gate A: CR-074 (the DDInter screening is the one that survives).

## What changed

**1. The rebuild (F2, cherry-picked from `a248e59`).** `agents/knowledge/scripts/build-demo-index.js` builds `data/interaction-index.json` from DDInter 2.0's own category files `data/build/ddinter_downloads_code_{A,B,H}.csv` (git-ignored, never committed; the owner allowed only A, B and H). Every earlier pair is kept and none changed level: 19 to 62 pairs, all nine seed ingredients covered, Warfarin x Ibuprofen is the DDInter `Major` row `DDInter1951,Warfarin,DDInter900,Ibuprofen,Major` of file B. No interaction row is written by hand. The plan's "blocked on Waddah" is resolved: the build tool is in the repository.

**2. The false-reassurance bug, fixed fail closed.** A DDInter category file lists the interactions of the drugs *in* that ATC category. With only A, B and H loaded, a pair whose two drugs are both outside those categories can never be in the index, yet both drugs were marked "covered", so an absent pair read as "no interaction recorded". Examples: Ibuprofen (M) x Ciprofloxacin (J), Atorvastatin (C) x Ibuprofen (M) (the seed's own `rx-002` x `rx-004`), and Ezetimibe x Amlodipine, the fixture the old TC-IX-02 test used as its "no interaction" case.

- The index now records `meta.categoryFilesLoaded` (`["A","B","H"]`, `meta.categoryRule`) and each seed drug's ATC top-level categories (`drugs[k].atcCategories`).
- The ATC codes come from the WHO ATC/DDD index (https://atcddd.fhi.no/atc_ddd_index/), read on 2026-09-24, each code with its source URL next to it in `data/seed-drug-scope.json`. Only the codes WHO lists under the single substance's own name are counted; combination codes are not (fewer categories can only make screening stricter). Every code that puts a drug in a *loaded* category was also read on its own WHO code page.
- `src/interactions.js`: an absent pair is `no_pair_in_source` only when one of its drugs has a loaded category; otherwise `pair_not_checkable`. A drug without categories counts as not loaded; an index without `categoryFilesLoaded` proves no absence at all.
- Screening (`src/screening.js`): `pair_not_checkable` pairs raise one `info` "cannot verify" alert, `pending_medical_review`, never the `auto_cleared` "nothing recorded" marker. The validator refuses such an alert if it is `auto_cleared` or if it names a pair the index holds (V3, V4), and a refused alert escalates the run.
- Travel check (`src/travel-check.js`): `cannot_verify` with `reason: pair_outside_loaded_categories`; the app still gets `could_not_identify`.
- The build refuses to write a category unless (a) the code behind it was read on its own WHO code page, (b) the drug has rows in that category's file, and (c) that file lists every partner of the drug found in the other loaded files. A check with nothing to cross-check against is a failure, not a pass. On the real files every claimed category passes (build output below).
- The seed drugs whose categories are loaded: Warfarin (B), Metformin (A), Prednisolone (A, H), Levothyroxine (H), Calcium carbonate (A), Cholecalciferol (A). Not loaded: Ibuprofen (C, G, M, R), Atorvastatin (C), Ciprofloxacin (J, S). The nine non-seed drugs of the earlier slice have no ATC data here and count as not loaded.

**3. The DDInter paper reference was wrong, and is corrected.** The index said "Xiong G, et al. DDInter 2.0: an enhanced drug interaction resource. Nucleic Acids Research 2025;53(D1):D1356." Xiong G is the first author of DDInter 1.0 (2022). The publisher's record (Crossref for doi:10.1093/nar/gkae726; Europe PMC for PMID 39180399) gives: Tian Y, Yi J, Wang N, Wu C, Peng J, Liu S, Yang G, Cao D. DDInter 2.0: an enhanced drug interaction resource with expanded data coverage, new interaction types, and improved user interface. Nucleic Acids Research 2025;53(D1):D1356-D1362. The build now writes that text (`PAPER` in `build-demo-index.js`), so every DDInter citation the agents write carries it.

**4. `npm run coverage`** lists each seed ingredient (covered with its DDInter id, or absent with the reason) with its ATC categories and whether their file is loaded, and every seed pair as checkable or CANNOT VERIFY with the reason and whether screening runs on it today. It exits 1 if the index does not record its loaded files, the ATC data is malformed, or the index's categories differ from the seed file's.

**5. Change requests.** CR-096 (`PROPOSED`): the exact DDInter citation for Warfarin x Ibuprofen, proposed as the real `sourceCitation` of the seed's `ia-001`; the seed is not edited. CR-097 (accepted by the lead session): the category rule.
