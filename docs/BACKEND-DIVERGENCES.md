**Appended as we go, never at the end** (the owner's BACKEND-NOTES rule). The master prompt's ON COMPLETION section asks for "every place where the real backend behaves differently from the mock, with the reason" — this is that list, started at Phase 0 from the reading alone. Each row: what the mock does · what the backend will do · why · the screen that could notice (none may). A row that turns out to make a screen behave differently is a **change request**, not an entry here.
