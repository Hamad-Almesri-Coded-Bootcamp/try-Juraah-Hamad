# Jur'ah (جرعة) — Phase 2 Refusal Matrix

**A rule with no test on this table is not enforced, whatever the code says.** One row per rule in `docs/BACKEND-NOTES.md` §3 (all 34, including the four D-014 gaps) plus the master prompt's minimum list. Every row names: the invariant · where the database or handler enforces it · the exact call that must be rejected · the test that proves it (`tests/integration/enforcement/<tag>.test.ts`, test title = row id) · the DB-level result the test asserts · the seam shape the screen still receives (D-022) · whether the **mock refuses today** (so nobody learns the wrong answer from the reference behaviour).

Sessions are the seeded ones in `API-SURFACE.md` §C, minted as signed cookies. "RLS 0 rows" means the statement ran and returned nothing; "raises `<name>`" means the named trigger/constraint threw and `withSession()` rolled back. Route rows paste HTTP status and body.
